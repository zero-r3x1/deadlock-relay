Deadlock Relay — by ноль

Приложение управляет исходящими соединениями Deadlock через брандмауэр Windows.
Для установки Python не нужен. При изменении правил приложение предложит получить права администратора.

Закрытие или удаление приложения не снимает установленные блокировки. Перед удалением откройте Deadlock Relay и нажмите «Снять блокировки».

Пресеты управляют ретрансляторами Valve, а не языком или гражданством игроков. RU использует Стокгольм как приближение, Китай — Гонконг.

Компоненты Qt, PySide6 и Python распространяются с лицензиями в папке licenses и описанием THIRD_PARTY.md.
